# Research

存放尚未转化为工程决策的外部调研材料。

每份硬件参考调研至少应包含：

- 项目名称和原始链接。
- 主要功能、主控和关键器件。
- 原理图、PCB、BOM、固件和结构文件的完整性。
- 开源许可证及商用限制。
- 是否有实物验证、版本记录和社区反馈。
- 可复用部分、不可复用部分和技术风险。
